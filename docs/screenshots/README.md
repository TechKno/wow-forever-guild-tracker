# Interface screenshots

These screenshots show the actual generated interface served by `npm run demo` on loopback. They use the repository's neutral Example Guild branding and entirely fictional characters, account links, Discord display names, recipes, requests, events and timestamps. No production database, member record, provider credential or authenticated production session was used.

The preview includes a visible fictional-data banner, disables sign-in and rejects writes. It does not call Blizzard or Discord. Names were substituted in the demo fixtures before rendering, rather than blurred over live screenshots.

- `noticeboard.jpg`: guild overview and recent activity.
- `roster.jpg`: character roster, preferred-role symbols and composition.
- `crafting.jpg`: requests, selected crafters, materials and request demand.
- `mobile.jpg`: roster at a 390 × 844 CSS-pixel phone viewport.
- `account.jpg`: owned characters, main/alt choices and connected accounts.
- `admin.jpg`: private administrator overview with fictional health and counts.
- `hierarchy.jpg`: compact, centred guild ranks and player representatives.
- `armory.jpg`: tabbed character card with fictional gear, statistics and an original neutral demo portrait.
- `armory-phone.jpg`: the tabbed armory at a 390 × 844 CSS-pixel phone viewport.

To refresh them, build the site, run `npm run demo`, open its loopback URL and capture the desired page using fictional fixtures only. Keep credentials, browser account details and real member activity out of public images.
